# PPA - PROGRAMAÇÃO PARALELA AVANÇADA
**Ementa**: Conceitos de sistema de computação paralela, modelos de computação (sequencial e paralela), noções de complexidade e escalonamento de algoritmos paralelos, implementação de algoritmos paralelos, avaliação qualitativa e quantitativa de algoritmos paralelos.

## Estrutura
```
course_ppa/
├── 1_classes/
├── 2_materials/
├── 3_assignments/
└── 4_repos/
```

## Diretórios
- **1_classes**: Aulas, anotações, resumos, slides próprios.
- **2_materials**: Materiais do professor, slides, artigos, referências.
- **3_assignments**: Trabalhos, exercícios, listas, projetos, relatórios.
- **4_repos**: Repositórios, códigos, exemplos de scripts.
