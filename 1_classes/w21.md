# MPI + OpenMP

Mandelbrot em MPI, [main.cpp](../4_repos/c_cpp/8_mpi_mandelbrot/main.cpp).

É possível combinar MPI com OpenMP, basta adicionar `#include <omp.h>`, após isso, basta:
```
#pragma omp parallel for schedule(dynamic)
for(int r = 0; r < chunk; ++r){
        for(int c = 0; c < max_column; ++c){
                complex<float> z;
                int n = 0;
                while(abs(z) < 2 && ++n < max_n)
                        z = pow(z, 2) + decltype(z)(
                                (float)c * 2 / max_column - 1.5,
                                (float)(r + rank * chunk) * 2 / max_row - 1
                        );
                // trabalhadores devem escrever na memoria de trabalho
                trabalho[r][c]=(n == max_n ? '#' : '.');
        }
}
```

# CUDA

- CUDA by example

SIMD, uma instrução que será executada de forma multipla e paralela.

Código que é executado em uma GPU, é chamado de **kernel**. *Kernels* são executados em blocos e blocos são executados em *grids*
> Os kernels, são compilados para serem direcionados para serem executados em GPU, pelo nvcc

- Host: Dispositivos de processamento c/ CPU
- Device: Dispositivo auxiliar de processamento (CPU)

> RTX 3090 possui 24 GB (hardware UDESC).

Memória de Textura, geralmente são estáticas, porém permite alterações
Memória constante, não pode ser alterada
Memória global, variável global, acessada por todas as threads.

O compartilhamento de memória é feito por bloco.

Warp, é o tamanho do bloco, exemplo 32 threads.

## API CUDA

Um código que executa no kernel não pode buscar nada na memória principal
Funções com retorno void, as funções sempre retornam na própria memória, pointeiro que foi passado.

`__global__`, pois é invocada no host e executada no device
